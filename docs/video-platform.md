# 发布平台清单

这是《风行迷踪》录制参与及授权确认书里「中国大陆境内平台」「中国大陆境外平台」两个勾选项的**具体范围**。

### 发给境外平台的是什么

按《个人信息保护法》的要求，把个人信息提供给境外接收方时，要先告诉你下面这些事。你勾选「中国大陆境外平台」，就表示你看过并同意：

- **提供的信息**：你的肖像、声音，以及你填写的姓名或网名、艺名（出现在画面、字幕、简介或署名里）。你的手机号、邮箱**不会**提供给任何平台。
- **目的**：公开发布《风行迷踪》正片、花絮、预告和宣传内容。
- **方式**：我们把成片上传到上面列出的平台账号，由平台依其自己的规则存储、展示、推荐和传播。平台对观众数据（观看、点赞、评论等）的处理，适用各平台自己的隐私政策。
- **你的权利**：你可以随时联系我们要求下架、调整或删除涉及你的内容（联系方式见确认书）；也可以直接通过下面各平台列出的入口向平台提出。
